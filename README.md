# G-FunkProp

**G-Funk Powered Propulsion / G-BIOS** is an offline, open-source audio-responsive electric propulsion simulator.

This repository is being bootstrapped for an MIT-licensed prototype. The aim is to demonstrate audio DSP, power-accounted propulsion mathematics, and speculative fictional visuals without conflating them with proven faster-than-light physics.

The initial working build is under preparation in a reviewable pull request. The final simulator will run entirely in a modern web browser without dependencies.
